# 截一隅 · 本机截图工作台

一个不依赖安装包的本机截图工具，交互方式接近微信截图：截图、导入、标注、裁剪、复制和保存都在浏览器本地完成，不会上传图片。

## 一、最快上手

### macOS 推荐启动方式

1. 双击项目里的 `start.command`。
2. 浏览器会自动打开 `http://localhost:8765`。
3. 第一次使用时，点击“开始截图”，在系统弹出的选择器中选择整个屏幕或某个窗口。
4. 截图完成后，在画布上编辑，最后点击“复制图片”或“保存 PNG”。

如果双击脚本没有打开页面，也可以在终端执行：

```bash
cd /Users/anyou/cola/coding-cola/project-20260815-165602-5060df7b
python3 -m http.server 8765
```

然后手动打开 <http://localhost:8765>。使用 `Ctrl + C` 停止服务。

> 建议通过 `http://localhost:8765` 使用，不要直接双击 `index.html`。浏览器在 `file://` 页面上可能禁止屏幕捕获或剪贴板权限。

## 二、基本操作

### 1. 截取屏幕或窗口

- 点击顶部“开始截图”，或按 `⌘ ⇧ X`。
- 在浏览器 / 系统选择器中选择“整个屏幕”或指定窗口。
- 确认共享后，画面会载入工作台。
- 若取消选择，不会改变当前画布。

当前版本先获取完整屏幕 / 窗口，再用“选择区域”裁剪；不是在系统选择器里直接框选区域。

### 2. 导入图片

有三种方式：

- 点击“导入图片”，选择 PNG、JPG、WebP 或 GIF。
- 把图片文件拖到中间画布区域。
- 复制图片后按 `⌘ V`，或点击“从剪贴板读取”。

如果同一文件需要重新导入，再次点击“导入图片”即可。

### 3. 标注图片

先点击工具栏中的工具，再在画布上拖动或点击：

- **画笔**：自由手绘。
- **矩形标记**：拖出矩形框。
- **箭头**：从起点拖到终点。
- **文字**：点击画布位置，在弹窗中输入文字并确认。
- **局部模糊**：拖选需要隐藏的区域。
- **标注颜色**：在右侧“工作偏好”中选择珊瑚红、深蓝、森林绿或琥珀黄。

标注后可以使用“撤销”和“重做”。

### 4. 裁剪图片

1. 选择工具栏中的“选择区域”。
2. 在画布上拖出需要保留的区域。
3. 点击选区下方的“裁剪选区”。
4. 裁剪结果会成为新的画布内容。
5. 如果不想裁剪，点击“取消”，或按 `Esc` 清除选区。

### 5. 复制和保存

- 点击“复制图片”，将当前成品复制为 PNG。
- 点击“保存 PNG”，下载到浏览器默认下载文件夹。
- 快捷键：`⌘ C` 复制，`⌘ S` 保存。
- 默认开启“截图后自动复制”；不需要时可在右侧关闭。

导出的图片不会包含正在显示的选区虚线或拖动预览线。

### 6. 最近截图与外观

- “最近截图”会在本机浏览器中保存最多 4 条记录，点击缩略图可重新打开。
- 点击“清空记录”可删除这些本机记录。
- 顶部月亮按钮可切换深色模式。
- “缩小 / 放大 / 适应窗口”只改变查看比例，不改变图片像素尺寸。

## 三、快捷键

| 快捷键 | 作用 |
| --- | --- |
| `⌘ ⇧ X` | 开始截图 |
| `⌘ C` | 复制当前图片 |
| `⌘ S` | 保存 PNG |
| `Esc` | 取消当前选区或拖动状态 |

Windows / Linux 浏览器通常可使用对应的 `Ctrl` 组合键。

## 四、常见问题

### 点击“开始截图”没有画面

- 确认页面是通过 `http://localhost:8765` 打开的。
- 在系统选择器中确认选择了整个屏幕或窗口，并点击允许 / 共享。
- 如果刚刚取消过授权，重新点击“开始截图”再试。
- 部分浏览器或系统策略可能不支持 `getDisplayMedia`，建议使用最新版 Chrome、Edge 或 Safari。

### 复制失败

- 确认当前页面有图片。
- 先点击页面空白处，再按 `⌘ C`。
- 如果浏览器没有给剪贴板权限，使用“保存 PNG”作为替代。

### 图片没有载入

- 仅支持 PNG、JPG、WebP、GIF 等图片文件。
- 不要把普通文档或文件夹拖入画布。
- 文件过大时请等待载入完成，或先缩小图片。

## 五、审核结论（当前版本）

已检查：

- 页面可解析，脚本标签完整。
- 屏幕捕获、图片导入、拖拽、剪贴板、画布指针操作、标注、裁剪、撤销 / 重做、复制、保存和本机最近记录代码均已接入。
- 已补充导出时清除选区虚线的问题，避免虚线被写入 PNG；重复选择同一个文件也可以再次触发导入。
- 剪贴板读取增加了超时兜底，权限或系统响应异常时会回退到提示使用 `⌘ V`，不会一直卡在等待状态。
- 最近截图读取和写入增加异常保护；大图超出浏览器 `localStorage` 配额时只提示无法保存记录，不会让页面初始化失败。损坏记录会被过滤，图片只接受 `data:image/...` 格式，并使用 DOM API 渲染，避免本地记录注入 HTML 属性。
- 快捷键监听改为兼容 `e.key` / `e.code`，并在文档层捕获；`⌘ C` 不再要求焦点必须位于页面空白处。点击过按钮后仍可复制，但在输入框或任意 `contenteditable` 编辑区域中不会抢走系统复制快捷键。
- 文字工具曾存在一个真实边界问题：点击文字工具会先进入指针流程，把 `null` 推入标注列表；现已阻止文字工具进入拖动流程，并通过实际输入测试确认不再报错。
- 选区操作栏已改为根据画布与工作区的实际屏幕坐标定位，避免画布居中、缩放或滚动时错位；已通过选区和裁剪测试。
- 自动复制是否成功仍受浏览器剪贴板权限和用户激活规则影响；失败时不会破坏截图，可手动点击“复制图片”。
- 图片处理在浏览器本地完成，项目没有上传接口或第三方依赖。

仍需在你的 Mac 上人工确认的项目：

- 系统屏幕捕获选择器和屏幕录制权限。
- 真实图片文件导入、拖拽和剪贴板权限。
- 实际下载目录、复制结果和各类标注的视觉效果。
